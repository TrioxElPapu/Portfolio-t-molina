## 📝 Cómo actualizar el contenido

### Usando JavaScript (funciones disponibles en `script.js`)

**Agregar un proyecto:**
```javascript
addProject('Título del Proyecto', 'Lenguaje', 'https://github.com/link-al-repo');
```

**Agregar una skill:**
```javascript
addSkill('Nombre de la Skill', 'Categoría');
```

**Actualizar información de contacto:**
```javascript
updateContactInfo('nuevo@email.com', 'https://linkedin.com/in/...', 'https://github.com/...');
```

### Editando directamente HTML

Puedes editar `index.html` para:
- Modificar información personal
- Agregar proyectos en la sección correspondiente
- Cambiar datos de contacto

## 🚀 Despliegue en Vercel

Este repositorio está conectado a **Vercel** para despliegue automático.

**Pasos para desplegar:**

1. Conecta tu repositorio GitHub a Vercel
2. Vercel detectará automáticamente los archivos
3. Cada push a la rama `main` se desplegará automáticamente

**Estado actual:** Conectado a `https://portfolio-t-molina.vercel.app`
